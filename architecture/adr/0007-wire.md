# Library-backed JSON hidden behind typed adapters

## Context

Dhall is the storage format, but maintaining a guest-side partial Dhall parser
is not a product goal. JSON libraries can handle syntax while generated
bindings handle domain types. Neither JSON nor Aeson defaults are a lossless
Haskell data contract by themselves.

## Decision

Use UTF-8 JSON messages via a small synchronous, private host/guest protocol.
Use Aeson 2.2.5.0 on the host and the unchanged `Text.JSON.Types` and
`Text.JSON.String` modules from `json-0.11` on MicroHs. The latter supplies
`runGetJSON readJSValue` and `showJSValue`; no umbrella-module dependency graph,
alternate parser backend or parser fork is required. The
[vendored inputs](../../vendor/README.md) record selected sources and notices;
[codec tests](../../tests/integration/codecs/README.md) exercise the boundary.
Preserve upstream notices under ADR 0022.

Kyyn generates mappings between library JSON values and constructors/fields of
the supported, compiler-inspected authored ADTs. Authors do not maintain codecs
or a second schema. Library parsing/printing and generated structural decoding
are separate responsibilities: the latter checks tags, fields and payload types.
Generated ADT mappings require real MicroHs round-trip tests, not only JSON-value
parser tests.

SDK-generated adapters own serialization, framing, request IDs, method dispatch,
contract matching and structured failures. Ordinary KB/plugin code never sees
`Value`, JSON text, pipe handles or response envelopes. The native host translates
disk values into this representation; it does not send executable Dhall expressions.

The wire is structurally checked on the host; it cannot carry the guest's GADT
index or continuation. A representative pair of private envelopes is:

```haskell
data GuestMessage
  = HostRequest RequestId CapabilityId MethodId WireValue
  | Completed WireValue

data HostMessage
  = HostResponse RequestId (Either HostCallError WireValue)
```

`WireValue` belongs to the selected JSON library/profile, not the public SDK.
`HostCallError` is an encoded, declared request failure; a broken frame/channel is
a protocol failure and need not pretend to be a well-formed response. Handshake
and initial-entry messages are additional protocol cases, not expanded here.
Recoverable errors that authored code handles must be part of the request's
declared result, for example `Either PluginError output`. An envelope-level error
with no such declared mapping aborts the invocation through the adapter; it is
never cast into the continuation's expected `x` or converted into an empty page.

The adapter decodes a frame, resolves its method in the invocation's available
capabilities, checks the input against the descriptor, then dispatches. It checks
the output against the result contract before replying. The guest's generated
decoder then reconstructs the precise `x` required by the suspended request in
[Program](0009-capabilities.md). A response ID match alone is not a type check.

For clarity, the pure codec boundary can have this shape without selecting a
JSON library or exposing it to authors:

```haskell
decodeFrame :: Bytes -> Either ProtocolDiagnostic GuestMessage
encodeFrame :: HostMessage -> Bytes
```

`decodeFrame` consumes one complete frame after framing has handled chunked pipe
reads. It validates envelope syntax, not capability availability or KB semantics.
Both functions use a library parser/encoder. Field/tag generation is our work;
reimplementing JSON parsing is not. The [contract checker](0005-contracts.md) is
the separate boundary that turns parsed structural inputs into `CheckedValue`.

Use one compact JSON object per LF-terminated frame. Library encoding escapes
newlines inside strings; pretty-printed/multiline frames are not supported.
This avoids the prototype's bespoke UTF-8 byte-counting transport. Stdout is only
protocol, stderr is diagnostic output. Verify this framing with the pinned
runtime, Unicode and real pipes; the plugin adapter proof exercises this under both
GHC and MicroHs.

The plugin adapter begins with `{arguments, snapshot}` and emits
`{tag: "HostRequest", id, capability, method, arguments}` or a terminal
`{tag: "Completed", result}`. Its host reply is `{tag: "HostResponse", id, result}`:
`result` encodes the request's typed `Either FetchError a` directly, without a
second error wrapper. Request IDs are canonical integer strings. Wrong IDs, tags,
fields or payload types abort before resuming the continuation; source failures
decode as ordinary `Left` values. Config and payload codecs come from inspected
Haskell types. SDK evidence/change envelopes have fixed private codecs.
The native broker interprets only the request row selected for the entry, through
ADR 0009's host capabilities. Verification must exercise both direct acquisition
and composed captured-evidence calls across the installed boundary.

## Value profile

Both library encoders emit non-ASCII text as literal UTF-8. Escaped controls,
quotes and backslashes remain normal JSON syntax. All Unicode scalar values are
representable, but the guest does not promise to accept every equivalent JSON
spelling: escaped UTF-16 surrogate pairs are unsupported by this library decoder.
After parsing and before dispatch or encoding, validate retained string values
and object keys recursively, rejecting surrogate Chars. Reject JSON numeric and
null nodes as outside this profile; numbers use strings and optionals use tags.
These are decoded-value checks, not another syntax scanner. Conformance tests
verify library-generated output; do not add a canonical-frame checking service.

| Contract value | Wire representation |
| --- | --- |
| Record/list/text/bool | Object/array/string/boolean |
| Integer, Natural, exact Decimal | Canonical decimal strings, parsed by typed bindings; never via `Double` |
| Nullary union case | `{"tag":"Case"}` |
| Payload union case | `{"tag":"Case","value":…}` |
| Optional | Explicit `None`/`Some` tagged cases, preserving nested optionals |
| Stable identity, date, instant | Documented strings, checked by corresponding SDK type |
| Binary/large document | Typed artifact reference, not arbitrary embedded bytes |

No function values, type expressions, imports, NaN/infinity, omitted-field
defaults or implicit union guessing. Arbitrary domain numbers do not use JSON
numbers in this profile. Exact decimal syntax and rounding policy are separate:
the shared arithmetic library owns operations; the KB chooses business rounding.
The scalar rows refer to selected existing library types recognized under ADR
0005, not any KB record whose name happens to be `Decimal` or `Date`. Inspect and
preserve relevant parameters such as fixed resolution, and prove the generated
library-type/string codec in both peers. Structural records do not become decimal
scalars by naming convention. Prefer a maintained numeric implementation over
inventing arithmetic to fit the wire table. Unsupported library/codec mappings
must be rejected, never silently represented as `Double`.

Arbitrary authored newtypes follow the ordinary constructor mapping: a positional
wrapper is tagged, and a named record wrapper is an object. Transparency is not
inferred from a type's name or from being a newtype. The string representation
for identities/dates applies only to recognized SDK/library scalar types with
their selected codecs, not a KB-authored type merely called `FactId` or `Date`.

Generated frames have unique field names. Decoding uses first-key-wins at each
object, matching the tested Aeson 2.2.5.0 behavior. Normalize the guest library's
association lists accordingly before structural decoding, including nested
objects. Dependency updates must rerun this conformance assertion. No semantic hashing
of arbitrary JSON source. JSON encoding must not introduce an extra candidate
identity or approval protocol; acceptance uses the Git base under ADR 0012.

## Protocol boundary and tradeoffs

Kyyn generates both adapters for its installed runtime; there is no protocol/SDK
version negotiation. Invocation checks contract identities, then supplies a typed
entry input. Guest messages are host-capability requests or terminal results; the host
answers each request once. One outstanding request per guest initially. A parent
KB can synchronously call a plugin in another invocation; no recursive plugin
call graph in the first profile. Unknown methods, mismatched identities and
unexpected message order fail before any requested effect is dispatched.

The outer invocation owns any nested plugin invocation and its resources.
Cancellation of the outer operation cancels outstanding child work and releases
its pipes/processes; no orphan guest waits forever for a response. Recoverable
plugin errors return as typed results to the suspended caller; fatal protocol or
process failures remain distinguishable. Per-call processes suffice initially;
pooling or reuse is not a prerequisite. Contract-compatible plugin result types
may be reused through generated bindings; re-project them only when domain
meaning requires it, not to cross the transport boundary.

Protocol changes update host and generated adapters together; rebuild guest artifacts
when the toolchain changes. A changed installed contract yields a clear repair instruction.
Process failure/cancellation follows ADR 0019, especially after external writes.

## Verification

Runtime integration tests cover raw Unicode and
controls, exact numeric strings and nested optionals, surrogate-pair rejection
without partial output, JSON-number rejection, truncated input, trailing garbage,
first-key normalization, and nested string/key checks. Exercise actual generated
ADT encoders/decoders in both directions, including unknown tags, missing fields
and wrong payload types; exchanging tagged JSON objects alone is insufficient.

Independent host/guest round trips: payload unions, `Some None`, empty values,
very large integers, exact decimals, Unicode/control characters, malformed and
truncated frames, duplicate keys, wrong methods and mismatched schemas. Include
actual runtime fact loading and a suspended multi-request program. The codec
and effect-encoding gates must not wait until the first external connector:
ADR 0021's reporting slice includes a typed KB tool with several host requests.
Exercise nested-call errors and cancellation as well as successful resumption.
No parser implementation is authorized by this ADR; generated field/tag mapping is the
limited codec work Kyyn consciously owns.
